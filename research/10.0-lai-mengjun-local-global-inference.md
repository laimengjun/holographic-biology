## 0. 一句话

"管中窥豹、一叶知秋、局部相似处处相似"不是玄学命题，而是一个**可推断性（identifiability）**命题：

> 当生成形态的规则维数远低于形态本身的维数时，任一小块局部样本都携带关于整体参数的信息；贝叶斯反演给出从局部到整体的最优估计；DNA 复制误差提供变异与噪声，使这种可推断性既有上限，也可以被测量。

张颖清当年提出的是"局部含整体信息"这一现象，并直接推到诊疗；本框架保留现象、换掉解释，把它改写成三个可测的组成部分。

## 1. 与张颖清的分野（这一节必须先说清）

| | 张颖清（1980s） | 赖孟峻框架（2026） |
|---|---|---|
| 核心主张 | 生物全息律、全息胚：局部是整体的缩影 | 局部对整体**可推断**，因为生成规则低维 |
| 证据形式 | 类比与个案（耳穴图、第二掌骨侧） | 互信息、协方差有效维数、反演误差收敛率 |
| 可否证 | 基本不可否证（任何相似都能算作证据） | 可否证：互信息不显著高于对照区即失败 |
| 落点 | 诊疗 | 形态发生的信息结构，不做诊疗主张 |
| 名称 | 生物全息学 | **沿用**"生物全息学"，但定义换掉 |

一句关键差别：旧说要求你"相信局部能反映整体"；本框架要求你"测量局部与整体的互信息，并检验它是否显著高于一个形态上等价、但传统上并不对应的对照区域"。

## 2. 三根支柱

### 支柱一：低维生成规则（发育的少参数性）

**命题**：形态 P 由少数参数 θ 生成，P = f(θ) + ε，且 dim θ ≪ dim P。
**依据**：
- Wolpert 1969 的"位置信息"：细胞按浓度阈值读取位置，这是少参数的编码方式。
- Turing 1952 的反应—扩散：两个扩散系数与几个反应常数，就能生成条纹、斑点、迷宫。
- 深同源性（Shubin, Tabin & Carroll 2009）：不同器官共享同一套调控核（如 Pax6、Hox），因此不同部位的"相似"有共同机制，不必诉诸神秘。
**数学后果**：f 的低维性使局部观测 o = g(P) 对 θ 保有信息；这就是"一叶知秋"的根据。
**可测**：形态性状协方差矩阵的有效维数（谱熵或 participation ratio），显著低于性状数即支持本支柱。

### 支柱二：DNA 复制误差——既是变异的源头，也是"全息噪声"

**命题**：复制误差使 θ 扰动；发育缓冲（canalization）吸收大部分扰动，剩下的表现为局部—整体映射的噪声。于是存在一个**权衡**：错误率越高，形态多样性越大，但局部对整体的可推断性下降得更快。
**依据**：突变率与表型噪声、发育不稳定性（developmental instability）的既有研究；基因调控网络的稳健性与可变性研究（Espinosa-Soto 等）。
**可测**：mutator 品系与对照品系的形态熵之比，与两者的互信息之比，预期呈负相关。
**这一条顺带解释了为什么"全息"在自然界只是近似成立**：误差是这套编码的固有噪声本底。

### 支柱三：反向推导＝贝叶斯反演

**命题**：从局部推整体是典型的不适定反问题，必须带先验；先验正来自支柱一（发育规则）。
**写法**：p(θ | o) ∝ p(o | θ) p(θ)。给定先验，估计误差随局部采样量 n 按 1/√n 收敛；先验不足时，高维性状上出现误差平台。
**意义**：这给"一叶知秋"一个精确含义——不是感应，是低维参数的可识别性加先验约束下的最优估计。

## 3. 可检验预测（P1—P5）

- **P1 有效维数**：同一物种内，形态协方差矩阵的有效维数显著低于性状数。
- **P2 互信息的尺度饱和**：局部窗口与整体参数的互信息随窗口面积增长，并在某个尺度饱和；该饱和尺度应与发育规则的相关长度同阶。
- **P3 噪声—推断权衡**：mutator 品系中形态熵上升、互信息下降，两者呈负相关。
- **P4 反演收敛率**：有先验时误差按 1/√n 下降；去掉先验则出现平台。
- **P5 对照区检验（最关键）**：若"局部对应内脏"成立，则该部位与内脏状态的互信息必须显著高于一个形态上等价、但传统上并不对应的对照区。**这是旧说唯一可被证伪的形式，也是本框架与旧说的分界线。**

## 4. 为什么"局部相似处处相似"在自然界到处出现

四条原因叠加，不需要任何超验假设：
1. 自相似是低维生成规则的几何后果（分形、脉序、叶序、反应扩散）。
2. 同源结构使不同部位共享调控核（深同源）。
3. 选择偏好可预测的形态，发育缓冲把噪声压下去。
4. 观察者本身在做贝叶斯推断，天然会把局部当证据。

"像"不是神秘，是低维 + 同源 + 稳定 + 推断的合成品。

## 5. 怎么用"生物全息学"这个名字

- **保留**：它指认的现象真实存在，只是解释换了；这个名字有认知基础，中文语境里"全息"天然带"局部含整体"的意思。
- **切割**：必须写一句"本框架不继承其诊疗主张，也不以'全息'本身作为证据"。
- **对外三句话模板**：
  1. 现象是真的：局部确实携带整体信息，但那是统计意义上的。
  2. 原因是可说的：低维生成规则 + 复制误差 + 贝叶斯反演。
  3. 边界是硬的：这套东西不构成任何诊断或治疗依据。

## 6. 第一批可做的工作（不需要湿实验）

1. 用公开形态数据集（叶片轮廓、果蝇翅脉、人脸地标）算 P1：协方差有效维数。
2. 用同一数据算 P2：局部窗口与整体参数的互信息—尺度曲线（互信息估计器用 kNN 或 MINE）。
3. 用已发表的 mutator 品系数据做 P3 的元分析。
4. 整理 P5 的可行设计：先确定"传统对应区"与"形态等价对照区"，再取内脏状态的可测代理（如心率变异、皮温）。
这四项都是公开数据 + 统计，适合作为首篇预印本的内容。
